Tinjauan 30 hari

Ramalan semasa dan rujukan sejarah mempunyai tujuan berbeza. Hari 1–7 menggunakan ramalan yang tersedia untuk lokasi dipilih dalam tab Ramalan 7 hari. Hari 8–30 menunjukkan rekod pada tarikh sama tahun lepas, mengikut negeri/kawasan. Sejarah bukan ramalan bencana akan berulang. Tiada rekod tidak bermakna kawasan selamat.

Rekod ialah rujukan lokasi/tarikh, bukan bilangan bencana unik. Kejadian berterusan dan laporan pemerhatian boleh muncul lebih daripada sekali. Rekod ditandakan untuk semakan tidak diterbitkan. Tiada padanan PPL, PSM atau SLA dibuat untuk sejarah.

Import data sejarah

Admin sahaja · Excel → Pratonton → Sahkan import

Set permulaan dimuatkan secara automatik; tiada muat naik awal diperlukan.

Muat turun Excel permulaan, panduan admin atau prompt ChatGPT untuk kemas kini. Gunakan buku kerja terkini untuk kemas kini seterusnya.

Lembaran Historical_Events mesti mempunyai 14 tajuk lajur asal pada baris 1. Tarikh Excel, YYYY-MM-DD dan rentetan ISO tengah malam dalam fail permulaan disokong. Fail tidak diimport sehingga anda mengesahkan. Pendua dilangkau; konflik dan review_required=yes ditahan tanpa menggantikan rekod sedia ada.

Lihat contoh rekod baharu

Untuk meluluskan rekod ditahan, semak sumber, betulkan rekod dalam buku kerja Excel, tukar review_required kepada no selepas disahkan dan muat naik semula. Konflik dengan rekod diterbitkan tidak ditulis ganti; hubungi penyelenggara untuk pembetulan rekod asal.
